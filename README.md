# 🌤️ Веб-приложение погоды и геолокации

Тестовое задание для компании **«Программы и технологии»**.

Интерактивный адаптивный виджет на Vue 3, который автоматически определяет текущую геопозицию пользователя (через GPS браузера или по IP-адресу в качестве резервного метода) и выводит актуальную погоду. Также приложение поддерживает мгновенный асинхронный поиск погоды в любом городе России «на лету».

---

## 🚀 Ключевые особенности и архитектура

- **⚡ Технологический стек**: Vue 3 (Composition API / `<script setup>`), TypeScript, Vite, Vuetify 3, Axios.
- **📂 Чистая архитектура**: Логика приложения строго разделена на три независимых уровня:
  - `Services (api/)` — чистый транспорт Axios без зависимостей от Vue (трансформация технических ошибок).
  - `Composables (composables/)` — изоляция бизнес-логики и управление реактивным состоянием (`useLocation`, `useWeather`).
  - `Components / Pages` — только отображение данных и связь с UI.
- **🌐 Умный гео-фоллбэк**: Если пользователь запретил доступ к GPS-координатам, приложение автоматически бесшовно переключается на определение города по IP через российское API DaData (работает без VPN).
- **🔍 Динамический автокомплит**: Поиск городов через `v-autocomplete` интегрирован с API подсказок DaData. Поиск защищён от ошибок и выдаёт строго города (без улиц и домов).
- **🛡️ Обработка ошибок и оффлайн-режим**: Все сетевые запросы покрыты Type Guard проверками (`axios.isAxiosError`). Приложение корректно реагирует на отключение интернета (`ERR_NETWORK`), таймауты сервера и ошибки 404, выводя понятные уведомления.
- **🧪 Тестирование**: Покрыты Unit-тестами утилиты преобразования данных, а также выполнен изолированный компонентный тест-сценарий (Vitest + `@vue/test-utils`).

## 🛠️ Инструкция по развертыванию проекта

### 1. Клонирование репозитория

Склонируйте проект к себе на локальный компьютер и перейдите в папку с ним:

```bash
git clone https://github.com/alexkostinprog/weather
cd weather
```

### 2. Установка зависимостей

Установите все необходимые пакеты с помощью стандартного пакетного менеджера NPM:

```bash
npm install
```

### 3. Настройка переменных окружения (API Key)

Для работы интеграции с погодой необходимо настроить ключ доступа:

1. Скопируйте файл конфигурации-примера:
   ```bash
   cp .env.example .env
   ```
   _(Для Windows в PowerShell: `copy .env.example .env`)_
2. Откройте созданный файл `.env` и вставьте ваши личные API-ключи

```ini
# API ключ для OpenWeatherMap (Погода)
VITE_WEATHER_API_KEY=ваш_ключ

# API ключ для HTTP Геокодера Яндекс.Карт (Координаты -> Адрес)
VITE_GEOCODER_KEY=ваш_ключ

# API Токен DaData (Подсказки городов и определение по IP)
VITE_DADATA_API_KEY=ваш_токен_из_личного_кабинета_dadata
```

_Примечание: Переменные обязательно должны начинаться с префикса `VITE_`, чтобы сборщик Vite прокинул их в клиентскую часть приложения._

### 4. Запуск сервера разработки

Запустите локальный dev-сервер:

```bash
npm run dev
```

После запуска приложение будет доступно в браузере по адресу: [http://localhost:5173](http://localhost:5173) (или указанному в консоли).

## 🧪 Запуск тестирования

В проекте настроен фреймворк **Vitest** для выполнения автоматических тестов в изолированном окружении `jsdom`.

Запуск тестов в режиме отслеживания изменений (Watch mode):

```bash
npm run test
```

## 📦 Сборка для Production

Для компиляции проекта, проверки типов TypeScript и оптимизации файлов перед деплоем на хостинг выполните команду:

```bash
npm run build
```

Готовая оптимизированная сборка будет находиться в папке `/dist`.
